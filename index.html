Sobre Mim

Durante minha jornada de aprendizado, tive a oportunidade de aplicar conceitos em projetos práticos, onde desenvolvi aplicações em Java e Node.js, e construí interfaces web interativas utilizando HTML, CSS e JavaScript. Também possuo experiência com C++ e com a estruturação e desenvolvimento de Bancos de Dados, compreendendo a importância de um back-end bem fundamentado para o sucesso de qualquer aplicação. Acredito no aprendizado contínuo e, por isso, invisto meu tempo em plataformas como a Alura para expandir minhas competências. Atualmente, estou aprofundando meus conhecimentos em Python e C#, além de reforçar conceitos essenciais como boas práticas de programação e lógica, que considero a base para a escrita de um código limpo, eficiente e escalável.
